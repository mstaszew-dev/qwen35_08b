# Qwen3.5 0.8B Local Gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a GraalVM native-image Kotlin gateway in `~/qwen35_08b` that serves `Qwen3.5-0.8B-Q4_K_M.gguf` via a llama.cpp `llama-server` child process on `127.0.0.1:8091`, autostarts at login, unloads the model after 10 idle minutes, and replaces the tailnet `laptop` qwen slot in msrouter/opencode.

**Architecture:** A resident Kotlin gateway (`qwen35-gw`, port 8091) owns a llama-server child process (port 8101). Every request is transformed in pure functions (model rewrite, vision strip, thinking off, deterministic 128K->32K pruning) then forwarded to llama-server; responses (incl. SSE) are relayed. An idle scheduler kills llama-server after `IDLE_MINUTES` without requests; the next request cold-starts it (~0.7 s load). A launchd LaunchAgent keeps the gateway resident from login.

**Tech Stack:** Kotlin 2.1.0 (JVM), GraalVM native-image (JDK 21.0.2, already installed at `~/qwen35_08b/toolchain/graalvm`), Gradle 8.14 (`~/qwen35_08b/toolchain/gradle-8.14`), `kotlinx-serialization-json` 1.7.3, JDK `com.sun.net.httpserver` + `java.net.http`, JUnit 5, llama.cpp (built from source, already at `~/qwen35_08b/llama.cpp`, binary at `~/qwen35_08b/bin/llama-server`), GGUF already downloaded at `~/qwen35_08b/Qwen3.5-0.8B-Q4_K_M.gguf` (503 MB).

```kotlin
object TokenEstimator {
    fun estimateTokens(messages: JsonArray, tools: JsonArray?): Int
    fun pruneToBudget(messages: JsonArray, tools: JsonArray?, budget: Int): JsonArray
}
object RequestTransform {
    fun stripVision(messages: JsonArray): JsonArray
    fun forceThinkingOff(body: JsonObject): JsonObject
    fun rewriteModel(body: JsonObject, modelId: String): JsonObject
    fun prepare(body: JsonObject, modelId: String, pruneBudget: Int): JsonObject
    // prepare = stripVision + forceThinkingOff + rewriteModel + pruneToBudget(messages), returns full body
}
```

**Behavior spec (deterministic):**
- `estimateTokens`: for each message, `chars = sum(len(text))` of string content OR of each `content[]` part's `text`; plus 10 per message. For tools (if non-null): add `JSON.stringify(tools).length`. Return `floor(chars / 4)`. Fields are read via `JsonObject`/`JsonElement` accessors, never via reflection.
- `stripVision`: for every message whose `content` is a `JsonArray`, keep array elements that are NOT objects with `type == "image_url"`. If an array becomes empty after filtering, replace that message's `content` with the string `"[image removed]"`. Messages with string content are unchanged. Messages with object content (e.g. `{"type":"text",...}` / tool-call objects) are unchanged.
- `forceThinkingOff`: returns a copy of `body` where:
  - any top-level key `thinking`, `reasoning`, `reasoning_effort` is REMOVED;
  - `chat_template_kwargs` is set to an object that has `enable_thinking=false` (merging/keeping any other entries already present).
- `rewriteModel`: copy of `body` with `model` set to `modelId`.
- `pruneToBudget`: given `messages` + `tools` + `budget`, if `estimateTokens(messages, tools) <= budget` return messages unchanged. Otherwise remove non-system, non-LAST messages from the FRONT (a `message` is system when `role == "system"`; the LAST message is always kept) until it fits. If still over (i.e. system + last alone exceeds budget): truncate the LAST message's string content only, from the END (keep the head), shrinking until the total fits; if the last message uses an array content, convert it to a single string `"[truncated]"` first then truncate. Tools are NEVER modified or dropped. Budget is always applied to `estimateTokens(messages, tools)`.
- `prepare`: returns `rewriteModel(forceThinkingOff(stripVision-pruned body))` — i.e., strip vision from messages, prune to budget, force thinking off, rewrite model, and keep all other top-level keys (stream, max_tokens, temperature, tools, ...) intact. Order: strip vision, then prune, then think-off, then model rewrite.

```kotlin
package com.zcode.qwen35gw.model

import kotlinx.serialization.json.*

object TokenEstimator {
    fun estimateTokens(messages: JsonArray, tools: JsonArray?): Int {
        var chars = 0
        for (m in messages) {
            val obj = m as? JsonObject ?: continue
            val content = obj["content"]
            chars += contentTextLength(content) + 10
        }
        if (tools != null) {
            chars += tools.toString().length
        }
        return chars / 4
    }
    private fun contentTextLength(content: JsonElement?): Int {
        return when (content) {
            is JsonPrimitive -> content.content.length
            is JsonArray -> content.sumOf { part ->
                if (part is JsonObject && part["type"]?.content == "image_url") 0
                else (part as? JsonObject)?.get("text")?.let { (it as? JsonPrimitive)?.content?.length } ?: 0
            }
            else -> 0
        }
    }
}
```

```kotlin
data class GatewayConfig(
    val listenPort: Int,
    val upstreamHost: String = "127.0.0.1",
    val upstreamPort: Int,

    val pruneBudget: Int = 30_000,

class Gateway(
    private val cfg: GatewayConfig,
    private val upstream: Upstream,
    private val process: LlamaServerProcess,
    private val tracker: RequestTracker,
) {
    fun start()   // bind HttpServer on cfg.listenPort, register handlers
    fun stop()
}
interface Upstream {
    fun chatCompletions(body: String): UpstreamResult
}
sealed class UpstreamResult {
    data class Success(val status: Int, val contentType: String?, val bodyBytes: ByteArray) : UpstreamResult()
    data class Failure(val message: String) : UpstreamResult()
}
class HttpUpstream(private val baseUrl: String, private val ready: (String /*canonical model*/) -> Unit = {}) : Upstream
```
Handlers on the JDK `HttpServer` (non-daemon executor threads):
- `POST /v1/chat/completions`: parse body `JsonObject`; call `RequestTransform.prepare(body, cfg.modelId, cfg.pruneBudget)`; `tracker.begin()`; if `process.state() != RUNNING` then `process.start()`; if still not running -> `tracker.end()`, return 503 `{"error":{"message":"model not loaded","type":"service_unavailable"}}`. Else forward via `upstream.chatCompletions(Json.encodeToString(prepared))` and relay:
  - `Success`: set HTTP status + `Content-Type` (from upstream); if upstream content-type is `text/event-stream`, write `bodyBytes` directly and flush (raw SSE passthrough); else write bodyBytes.
  - `Failure`: 502 `{"error":{"message":...}}`.
  - finally `tracker.end()` in the relay path.
  - The canonical-model readiness callback `ready` records last model id (unused beyond logging; default no-op).
- `GET /v1/models`: return `{"object":"list","data":[{"id":cfg.modelId,"object":"model","owned_by":"qwen35-gw"}]}` with `Content-Type application/json`.
- `GET /healthz`: return JSON `{"status":"up","model":cfg.modelId,"loaded":(process.state()==RUNNING),"active":tracker.active()}`.

JDK `HttpServer` usage: `com.sun.net.httpserver.*`; set `server.executor = Executors.newCachedThreadPool { r -> Thread(r).apply { isDaemon = false } }`.
